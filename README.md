# 🧠  SmartReview AI-Fake Review Detection System  

### Enterprise Category-Based Fake Review Detection System  
AI • NLP • Machine Learning • Streamlit Dashboard

---

## 🚀 Project Overview

SmartReview AI Platform is an intelligent fake review detection system built using Natural Language Processing (NLP) and Machine Learning.

It provides:

- 📊 Interactive analytics dashboard
- 🧠 TF-IDF + Logistic Regression model
- 📈 Advanced visualizations
- ☁️ Word Cloud analysis
- 🔁 Confusion matrix evaluation
- 🔍 Real-time review prediction
- 🗂 Category-based filtering system

This project is designed in a SaaS-style enterprise dashboard format.

## ▶️ How to Run Locally

1️⃣ Clone the repository

```
git clone https://github.com/its-laksh/Fake-Review-Detection-System
```

2️⃣ Move into project folder

```
Fake-Review-Detection-System
```

3️⃣ Install dependencies

```
pip install -r requirements.txt
```

4️⃣ Run the application

```
streamlit run app.py
```

The app will open in your browser.
